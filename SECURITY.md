# Security model

## Deliberate unsafe boundary

The installed rule is:

```text
hermes ALL=(ALL:ALL) NOPASSWD: ALL
```

It gives the `hermes` Unix account unrestricted root execution without a
password. The gateway remains a user service, but that distinction limits
accidental service privilege only; it does not constrain commands available to
the agent. Do not install this on a shared host, a production server, or a VM
with secrets outside the intended scope.

Bootstrap requires `--enable-unsafe-root`, validates the rule with `visudo`,
and refuses to proceed if a system-level Hermes gateway unit would create a
second privilege boundary.

## Trust boundaries

- System/user/developer instructions remain authoritative over all recalled
  content.
- Web pages, browser observations, external MCP results, and imported records
  are stored as `untrusted` and cannot claim high trust through the provider
  API.
- The redactor removes common API-key, bearer, cookie, JWT, private-key, and
  credential-assignment patterns before SQLite, Markdown, JSONL, or provenance
  materialization. It is defense in depth, not a password manager.
- Chrome DevTools MCP uses loopback CDP only. The browser profile is not in
  Git and is not copied by the project backup scripts.
- Codex MCP is local stdio. No credentials or OAuth tokens are generated by
  this project.

## Data protection

The active vault directory is mode `0700`; SQLite, state, Markdown, and JSONL
files are mode `0600`. SQLite WAL/SHM files are also tightened to `0600`.
Backups remain private under `$HERMES_HOME/backups` and include a manifest that
states the browser profile was excluded.

The repository ignore rules reject runtime databases, auth material, browser
profiles, sessions, JSONL, keys, and common token formats. Run
`scripts/validate-public-tree.sh` before staging or publishing.

## Operational rules

1. Keep CDP bound to `127.0.0.1`; fail validation if it binds to LAN or wildcard
   addresses.
2. Keep the gateway as the `hermes` user service; do not create a system
   `hermes-gateway.service`.
3. Do not place `.env`, `auth.json`, browser cookies, or a browser profile in
   this repository or in public issue output.
4. Treat durable memory as evidence with provenance. Explicitly forget or
   supersede records; do not silently rewrite history.
5. Back up before changing config, packages, or provider code. Test rollback
   on a disposable clone before relying on it for incident recovery.

## Incident response

If the VM is exposed unexpectedly, disconnect it from the network, stop the
user gateway, preserve the private backup and journal, and remove
`/etc/sudoers.d/hermes-unsafe-autonomy` only after confirming the gateway is no
longer executing. Rotate any credential that may have been visible to the
agent; redaction cannot recover a secret already sent to a remote model,
browser, or MCP server.

To remove the project-owned integration after a backup:

```bash
scripts/uninstall.sh --yes --remove-mcp --remove-timer --remove-unsafe-root
```

Review the resulting `visudo -cf /etc/sudoers` output and service state. The
uninstall script intentionally preserves sessions and browser profiles.
